The [wage level lookup](/tools/wage-levels) showed DOL's four wages for a job and area. It now also estimates which of the four your job will likely get. Enter what the job requires (the degree, the months of experience, a foreign language, supervising, travel) and it shows the level, each step that added to it, and that level marked on the area's four wages.

## How it works

DOL starts every wage request at Level I and adds a level for each thing the job requires beyond the occupation's usual entry point. Its written guidance sets the steps. Experience counts against the occupation's O\*NET Job Zone, and a degree counts against the education the occupation usually needs. Both come from DOL's own yearly table for each occupation, so the estimate changes when DOL updates it each July.

Required travel isn't in DOL's written steps. In DOL's own decisions, though, it adds a level for many professional jobs, so the estimate counts it where those decisions show it.

## How often it's right

We ran the estimate on 68,116 of DOL's PERM wage decisions from April to September 2026. It matched DOL's level 84% of the time and came within one level 99% of the time. The rest comes down to the job's duties, which DOL reads and doesn't publish, so the page calls it an estimate.

## Where else it shows

- A case in your account that has a job code links to the estimate with the code filled in.
- The [wage requests page](/pwd-cases) links it, beside how DOL sets a prevailing wage.
- [How DOL sets a prevailing wage](/guides/how-dol-sets-a-prevailing-wage) explains each step.

The page also answers from DOL's published wage file when DOL's live wage search doesn't respond, and says which one it used.
